## 1. 背景（作者の依頼 2026-10-17）

チャット欄は **攻略情報を交換しあう場** であり、**各タイトルの盛り上がり具合を可視化する装置** でもある。
1.x は「右下の 💬 を押すと小さな窓が開く」だけで、盛り上がりが外から見えない。依頼は次のとおり。

- スマホでコメントを開くとキーボードでチャット欄が隠れる。入力中に何を打っているか分からない（**不具合。SDK 1.6.2 で先に直した。2 章**）
- YouTube のコメント欄のような UI が理想
- いいね・返信・編集（編集済み表記）
- PC では常にタイムラインが右側に出ているくらいにしたい（スマホは制約があるので無理のない範囲で）
- プレイヤーアイコンを bearko.games 全体で共通に。ポータルでも各タイトルのマイページでも変えられる（他のゲームにも効くと伝える）
- ポータルでは、タイトル横断のコメントを画面上部に流す。タイトル横断のタイムラインも見られる（投稿されたタイトル名を併記）

## 2. 先に直した不具合（SDK 1.6.2）

| 症状 | 原因 | 直し |
|---|---|---|
| 開いた瞬間にキーボードが出て窓が隠れる | 開くときに入力欄へ自動でフォーカスしていた | 指で触る端末（`pointer: coarse`）では自動フォーカスしない。入力欄を押したときだけキーボードが出る |
| 入力欄がキーボードの下に隠れ、Chrome が画面をずらすと窓ごと流れる | `position: fixed` の窓はキーボードで縮まない | スマホでは窓を下から出る **シート** にし、上端と高さを `visualViewport`（いま見えている範囲）から決める。キーボードが出ると見える範囲が縮むので、入力欄は常にキーボードのすぐ上に来る |

Playwright で `visualViewport` を差し替えて確かめた（キーボード 340px・ずれ 120px でも入力欄が見えている範囲の内側に収まる）。

## 3. 目指す形

```
PC（1100px 以上）                           スマホ
┌────────────────────┬──────────┐          ┌──────────────┐
│                    │ いまの会話 ▸│          │  ゲーム        │
│   ゲーム（いまの幅） │ [書く…]   │          │              │
│                    │ ●名前 Survivor│         │       💬 ←押す│
│                    │  本文      │          ├──────────────┤
│                    │  ♡3 返信 2 │          │ シート（会話） │
│                    │ ●名前 Factory│         │ ●名前 本文    │
│                    │  本文      │          │  ♡ 返信       │
│                    │  └ 返信…   │          │ [書く…][送る] │
└────────────────────┴──────────┘          └──────────────┘
```

- **PC：右側に常に出ている「ドック」**（幅 320px。▸ で畳める。畳んだかどうかは端末に覚える）。ゲームの表示はいまのまま、空いている右側に重ねる。ゲームが右端まで使う画面（Fortress の戦闘など）では、ゲームが `setVisible(false)` で隠すのは 1.x と同じ
- **スマホ：💬 → シート**（2 章）。常時表示はしない。かわりに **未読の数** と、ポータルの上部の流れ（7 章）で盛り上がりを見せる
- **1 件の見た目（YouTube 風）**：アイコン・名前・タイトルの札・時刻 ／ 本文 ／ ♡ いいね（数）・返信（数）・自分のものなら 編集・消す ／ 返信は「返信 N 件を見る」で畳む
- **並び**：**新しい順** と **いいね順** を切り替える（既定は新しい順。上が最新）。いいね順は部屋から「いいねの多い親 50 件」を取り直す。入力欄は **PC は上**（YouTube と同じ）、**スマホは下**（キーボードのすぐ上）

## 4. いいね・返信・編集

| | 決まり |
|---|---|
| いいね | 1 人 1 件 1 回（押し直すと取り消し）。ログインして名前を決めた人だけ。数だけ見せる（誰が押したかは出さない）。自分の発言にも押せる |
| 返信 | **1 段だけ**（YouTube と同じ。返信への返信は同じ段に並ぶ）。返信は親の下に畳んで出す。親が消えたら返信も消える（親が消えたあとの返信は宙に浮くため。消すのは本人か管理者） |
| 編集 | 本人がいつでも。本文の横に **「編集済み」**。編集の履歴は残さない（管理画面も最新だけ） |
| 消す | 本人か管理者。1.x と同じ |
| 連投 | 発言は 1.x のまま（2 秒・10 分 60 件）。いいねは 10 分 120 回、編集は 10 分 30 回 |
| 残す長さ | **直近 2,000 件 または 30 日**（1.x は 500 件・7 日）。タイムラインで遡るので長くする。SQLite の容量は 1 件 300 バイトでも 600 KB |
| 文字数 | 200 文字のまま。返信も同じ |

## 5. しくみ

### 5.1 部屋（Durable Object の SQLite）

```sql
ALTER TABLE messages ADD COLUMN parent INTEGER;        -- 返信なら親の id
ALTER TABLE messages ADD COLUMN edited_at INTEGER;     -- 編集した時刻（無ければ未編集）
ALTER TABLE messages ADD COLUMN likes INTEGER NOT NULL DEFAULT 0;   -- いいねの数（下の表から数え直せる）
CREATE TABLE likes (msg INTEGER NOT NULL, uid TEXT NOT NULL, at INTEGER NOT NULL, PRIMARY KEY (msg, uid));
```

- 部屋は 1 つのまま。D1 には書かない（SPEC-004 3.2 の費用の考え方は変わらない）
- つないだ直後に送る「直近」は **親 50 件 ＋ その返信**。遡るときは `GET /api/chat/messages?before=<id>` で 50 件ずつ

### 5.2 やりとり（WebSocket。1.x に足す）

| 客 → 部屋 | 部屋 → 全員 |
|---|---|
| `{ t: 'msg', text, parent? }` | `{ t: 'msg', id, uid, name, avatar, game, text, at, parent }` |
| `{ t: 'like', id, on: true/false }` | `{ t: 'like', id, n }`（本人には `{ t: 'liked', id, on }` も） |
| `{ t: 'edit', id, text }` | `{ t: 'edit', id, text, editedAt }` |
| （HTTP）`DELETE /api/chat/messages/<id>` | `{ t: 'del', id }`（返信も一緒に） |

### 5.3 共通アイコン（D1）

> **2026-10-18 SPEC-006 で変わった**：選べるのは最初からの 3 体（既定は MCHウォーリアー）と、持っているトロフィーのアイコンだけ。選ぶ窓は「アイコン図鑑」になった。

```sql
-- migrations/0007_avatar.sql（番号は実際の次番）
ALTER TABLE users ADD COLUMN avatar TEXT;   -- MCH のヒーロー id（例 "10042"）。無ければ既定の絵
```

- `GET /api/me` が `avatar` を返す。`POST /api/me/avatar { id }` で変える（ログインした人だけ。`null` で既定の絵に戻す）。id の形（`hero:数字` / `ext:数字`）だけを確かめ、絵が無ければ画面が既定の絵に落とす（Worker から資産リポジトリを引かない）
- 絵は資産リポジトリ（bearko/mycryptoheroes）の raw URL。**アップロードはしない**（審査と保存の費用が無料枠に合わない。ヒーローの絵なら世界観にも合う）
- 発言には `avatar` を載せる（部屋は接続のときに Worker から受け取る。1.x の `{ uid, name, game, banned }` に足す）。**名前と同じで、変えると以後の発言から変わる**（過去の発言は接続時の絵のまま。部屋は D1 を読まない）
- SDK：`BearkoGames.getUser().avatar`、`BearkoGames.setAvatar(id)`、`BearkoGames.avatarUrl(id)`。各タイトルのマイページは、この 3 つで選ぶ画面を作る。**選ぶ画面には「bearko.games 全体のアイコンが変わります」と書く**（作者の依頼）
- ポータルの `/me/` にも同じ選ぶ画面

### 5.4 SDK 1.7.0

| | 中身 |
|---|---|
| `init({ chat: { layout: 'dock' \| 'float', dockMin: 1100 } })` | `dock`：広い画面では右側のドック、狭い画面ではシート。`float`：1.x の窓（既定は `dock`。ゲームが止めたければ `float`） |
| `chat.mount(el)` | **自分の場所に描く**（ポータルの `/chat/` と、ゲームが自前の場所に置きたいとき）。fixed にしない |
| `chat.like(id)` / `chat.reply(id, text)` / `chat.edit(id, text)` | 窓を使わないゲーム（`ui: false`）のため |
| `chat.onMessage(fn)` | 1.x のまま。`like` / `edit` / `del` も流す（`fn({ t, … })`） |
| `chat.stats()` | タイトルごとの直近 24 時間の件数（7 章の「にぎわい」） |
| `chat.setSort('new' \| 'likes')` | 並び順（9 章 Q4） |
| `chat.onCompose(fn)` / `chat.layout()` | 入力欄に入った・出た（Factory はドックでは書いているあいだだけ止める）／いまの形（`dock` / `float` / `sheet`） |
| `BearkoGames.openAvatarPicker()` | アイコンを選ぶ窓（ヒーロー／エクステンションのタブ・名前で絞る・「bearko.games 全体のアイコンが変わります」）。各タイトルのマイページはこれを呼ぶだけ |

### 5.5 ポータル

- **上部の流れ**：トップの一番上に、直近の発言を 1 行ずつ右から左へ流す（10 件を繰り返す。`prefers-reduced-motion` では流さずに 1 件ずつ切り替える）。押すとタイムラインへ
- **タイムライン `/chat/`**：タイトル横断の全件。各発言にタイトルの札（1.x の `game` の札をそのまま）。タイトルで絞れる。PC は 2 列（左に絞り込みと「にぎわい」、右にタイムライン）、スマホは 1 列
- **「にぎわい」**：トップのゲームの札に「直近 24 時間 N 件」（0 件は出さない）。`chat.stats()`
- 1.x の「下の帯」は上部の流れに置き換える

## 7. 費用（DAU 100）

| | 1 日の呼び出し | 備考 |
|---|---|---|
| 発言 2,000 ＋ 接続 1,000 | 3,000 | 1.x と同じ |
| いいね（1 人 10 回） | 1,000 | DO の書き込み |
| 編集・返信 | 300 | |
| ドックで常につなぐ人の ping | 0 | `setWebSocketAutoResponse` で部屋を起こさない |
| `/api/me/avatar` | 50 | D1 の書き込み（無料 10 万行／日） |
| 合計 | **約 4,400 / 日** | 無料枠 10 万の 5% |

ドックで「常につないでいる」人が増えると接続の時間が延びるが、眠っている接続は GB 秒に数えない（SPEC-004 3.2）。
